# 4 分钟国特主演示脚本

## 演示前硬检查

- 主环境、备用环境均登录一次，确认 `/api/health`、PostgreSQL、模型 API 和 Nginx SSE 正常。
- 预先打开：数据看板、Agent 诊断、案例审核、知识图谱、`evidence/` 报告目录。
- 主演示固定使用“数控车床主轴周期性异响”，不要临场更换无标注问题。
- 禁止口头宣称尚未生成的 Recall、并发或 LoongArch 指标；只展示证据文件中的实测值。

## 时间轴

| 时间 | 操作 | 解说重点 | 必须出现的证据 |
|---|---|---|---|
| 0:00-0:20 | 登录并进入设备档案 | 系统不是孤立问答，而是围绕一机一档组织检修知识 | 设备型号、位置、维修时间线 |
| 0:20-1:35 | 打开 Agent 诊断，提交“数控车床主轴周期性异响” | Agent 使用结构化动作协议，自主调用手册、案例、图谱和设备历史，不暴露内部思维链 | 两种以上工具、每次耗时、成功/失败状态、引用卡 |
| 1:35-2:05 | 展开诊断报告与风险提示 | 每条关键结论带证据编号；高压、带电、带压作业要求人工确认 | `[E1]` 引用、来源文档、风险提示 |
| 2:05-2:55 | 提交一条案例并切换审核员采纳 | 新知识不是直接污染生产库，而是审核后入检索库和图谱，关系保留来源、版本与审核状态 | pending → approved、关系证据接口、实体别名 |
| 2:55-3:30 | 回到同类问题再次检索 | 展示知识闭环对后续检索的影响，强调可回滚和审计 | 新案例引用、审核操作日志 |
| 3:30-4:00 | 展示评测与国产化证据包 | 用原始 JSON/Markdown 收口，不用口头估计；说明 SQLite 仅回退，生产为 pgvector | 消融、Agent、30 并发、SBOM、SHA256、8 小时健康摘要 |

## 异常兜底

1. 模型 API 超时：保留界面的 `error + done` 事件，立即切换到普通检索，展示引用与安全提示。
2. 主环境网络异常：切换备用环境播放同一固定问题，不更改解说顺序。
3. PostgreSQL 异常：只用于说明 SQLite 回退保证可演示，不把回退结果当生产性能结论。
4. 图片模型异常：跳过图片环节，主演示仍由文本 Agent、知识闭环和证据包完整覆盖。

## 演练签字

每次演练记录日期、环境、操作者、总时长、异常、是否使用备用链路。主备环境各连续成功 3 次后才进入比赛版本冻结。
